# ⚽TheScoreHub - Football League Tracker

A dynamic and responsive web application for real-time football league tracking. This project displays live match scores, team statistics, and video highlights by integrating third-party sports APIs. Built using React.js for seamless navigation and a smooth single-page application experience.

## 🚀 Features

- 🟢 **Live Match Scores:** Real-time updates from ongoing football matches.
- 🎥 **Video Highlights:** Integrated match highlight when clicked on scores via API.
- 📱 **Responsive UI:** Fully optimized for desktop, tablet, and mobile.

## 🛠 Tech Stack

- **Frontend:** React.js, CSS, Axios, React Router
- **APIs:** Third-party football data API (API-Football)
- **Tools:** VS Code, Git, GitHub

## 🔧 Installation & Usage

```bash
# Clone the repository
git clone https://github.com/VikasPrasad27/thescorehub.git
cd thescorehub

# Install dependencies
npm install

# Start the development server
npm run dev

```
## 📦 API Setup

Register for a free API key at API-Football or any sports API provider and add it to your .env file.
```
# .env
YOUR_TOKEN=YOUR_API_TOKEN
```
